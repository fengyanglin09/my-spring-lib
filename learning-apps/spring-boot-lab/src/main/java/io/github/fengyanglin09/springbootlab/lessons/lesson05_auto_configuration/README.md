# Lesson 05: Auto-Configuration

## Status

Planned lesson. This README keeps the lesson path linked while the hands-on code
is still waiting to be built.

## Objective

Build the mental model for auto-configuration and why it usually backs off when
an application defines its own bean.

## Planned Study

- Read condition reports.
- Identify defaults driven by classpath dependencies.
- Override one default bean deliberately.
- Keep custom configuration narrow and easy to explain.
