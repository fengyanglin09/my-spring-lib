# Lesson 19: Pragmatic Lombok

## Status

Planned lesson. This README keeps the lesson path linked while the hands-on code
is still waiting to be built.

## Objective

Use Lombok where it improves Spring Boot code without hiding important design
choices.

## Planned Study

- Practice `@RequiredArgsConstructor`, `@Getter`, `@Value`, and `@Builder`.
- Avoid blanket `@Data` when mutability or equality matters.
- Discuss persistence-model traps.
- Keep Lombok as a helper, not the architecture.
