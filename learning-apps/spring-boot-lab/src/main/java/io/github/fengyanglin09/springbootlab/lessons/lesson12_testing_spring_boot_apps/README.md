# Lesson 12: Testing Spring Boot Apps

## Status

Planned lesson. This README keeps the lesson path linked while the hands-on code
is still waiting to be built.

## Objective

Choose the smallest Spring Boot test shape that proves the behavior under study.

## Planned Study

- Compare unit tests, MVC slice tests, data slice tests, and full
  `@SpringBootTest` contexts.
- Use test properties deliberately.
- Keep tests focused on one reason to fail.
- Show when a full context test earns its cost.
