# Lesson 06: Externalized Configuration

## Status

Planned lesson. This README keeps the lesson path linked while the hands-on code
is still waiting to be built.

## Objective

Learn how Boot separates application code from environment-specific
configuration.

## Planned Study

- Use `application.yml` for local defaults.
- Compare profiles, command-line overrides, and environment variables.
- Bind settings with `@ConfigurationProperties`.
- Validate typed configuration before business code uses it.
