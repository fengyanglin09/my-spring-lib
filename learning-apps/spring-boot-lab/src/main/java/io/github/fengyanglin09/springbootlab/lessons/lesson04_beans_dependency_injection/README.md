# Lesson 04: Beans And Dependency Injection

## Status

Planned lesson. This README keeps the lesson path linked while the hands-on code
is still waiting to be built.

## Objective

Learn how Spring Boot applications are built from beans connected through
constructor injection.

## Planned Study

- Compare `@Component`, `@Service`, `@Configuration`, and `@Bean`.
- Practice constructor injection with one small service graph.
- Use Lombok `@RequiredArgsConstructor` where it removes constructor noise.
- Call out when explicit constructors are clearer for the reader.
