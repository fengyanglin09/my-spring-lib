# Lesson 20: Pragmatic Vavr

## Status

Planned lesson. This README keeps the lesson path linked while the hands-on code
is still waiting to be built.

## Objective

Use Vavr as a boundary tool for explicit absence, failure, and validation rather
than as a new application architecture.

## Planned Study

- Compare `Option`, `Try`, `Either`, and `Validation`.
- Use Vavr in service/client boundary code.
- Convert Vavr values back to clear Spring MVC responses.
- Avoid turning ordinary Boot code into a functional maze.
