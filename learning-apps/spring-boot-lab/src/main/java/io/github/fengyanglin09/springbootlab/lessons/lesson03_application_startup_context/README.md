# Lesson 03: Application Startup And The Context

## Status

Planned lesson. This README keeps the lesson path linked while the hands-on code
is still waiting to be built.

## Objective

Treat startup as the moment Spring Boot assembles the application context.

## Planned Study

- Follow `SpringApplication` from the `main` method into context creation.
- Inspect command-line arguments and startup events.
- Study component scanning and the environment prepared before application code
  runs.
- Identify which beans exist because Boot started the application.
